Hướng Dẫn Tạo Kì Thi

Thông tin quan trọng

Khi tạo kì thi, vui lòng đảm bảo bạn đã đọc kỹ hướng dẫn sử dụng và tuân thủ đúng định dạng file.

File mẫu đáp án

Khi bạn upload file đáp án, hãy sử dụng file mẫu theo định dạng chuẩn của hệ thống. Tải file mẫu

Định dạng file

File đáp án phải có định dạng .docx hoặc .doc và tuân thủ cấu trúc như file mẫu để hệ thống có thể xử lý chính xác.

Thời gian xử lý

Hệ thống sẽ mất khoảng 1-2 phút để xử lý file đáp án sau khi upload, vui lòng kiên nhẫn chờ đợi.
